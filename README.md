# OMNI — PvE Battle Royale

渋谷スクランブル交差点を舞台にした一人称視点の PvE バトルロイヤルです。敵20人との戦いを制し、弾薬と回復パックを拾いながら、縮小する安全エリアで生き残りましょう。敵はライフルを構えて巡回し、プレイヤーを見つけるとスコープをのぞいて射撃します。Three.js と Vite で構築し、Cloudflare Workers に配信します。

## 遊び方

スタート画面で **DROP IN** を選ぶとマッチが始まります。敵は倒しても補充されず、全員を倒すと勝利、体力が尽きると敗北です。時間経過で安全エリアが縮小し、エリア外ではプレイヤーと敵の両方がダメージを受けます。`Esc` で一時停止し、**RESUME MATCH** から戻れます。キーボードとマウスを使う PC 向けです。

| 操作                     | 入力                                   |
| ------------------------ | -------------------------------------- |
| 移動                     | `W` `A` `S` `D`                        |
| 視点操作                 | マウス                                 |
| ジャンプ                 | `Space`（フック接続中は巻き取り）      |
| 左右のフックを射出／解除 | `Q` / `E`（照準先の建物の壁）          |
| ブースト                 | `Shift`                                |
| 武器切り替え             | `V`                                    |
| リロード                 | `R`                                    |
| 射撃                     | 左クリック（アサルトは押し続けて連射） |
| スコープ                 | 右クリックを押している間               |
| 一時停止                 | `Esc`                                  |

フック接続中の巻き取りは `Space` で操作します。スナイパーとアサルトマシンガンには別々の装弾数・予備弾薬があり、弾薬箱を拾って補給できます。回復パックは体力を最大40回復します。弾薬や回復パックは地上に配置され、近づくと自動で回収します。画面右上に残弾と安全エリアの残り時間、左上に体力が表示されます。敵を倒しても再出撃しません。キー割り当てはスタート画面または一時停止画面から変更でき、ブラウザーに保存されます。上下視点の感度も同じ画面で調整できます。

## ソース構成

- `src/main.ts`: ゲームループ、入力、HUD、各ゲームシステムの接続
- `src/weapons.ts`: 武器データ、弾薬消費・補給・リロード
- `src/battle-royale.ts`: 安全エリアとマッチの勝敗判定
- `src/loot.ts`: マップ上の弾薬・回復パック
- `src/game-utils.ts`: 乱数などの共通処理
- `src/settings.ts`: キー割り当てとマウス感度の設定
- `src/dom.ts`: 必須DOM要素の取得
- `src/enemies.ts`: 敵の巡回、索敵、射撃AI
- `src/enemy-visuals.ts`: 敵モデル、ライフル、体力ゲージ、射撃エフェクト
- `src/city.ts`: 街並み生成、建物内部・出入口、建物との衝突
- `src/flight.ts`: フックの飛行物理

## 開発

Node.js と pnpm を用意して、依存関係をインストールします。

```sh
pnpm install
pnpm dev
```

開発サーバーが表示する URL をブラウザで開いてください。テスト、lint、フォーマット、ビルドは次のコマンドで実行できます。

```sh
pnpm test
pnpm lint
pnpm fmt
pnpm build
```

`pnpm lint` は Oxlint に加えて TypeScript の型チェックを実行します。

## Cloudflare Workers へのデプロイ

Cloudflare CLI（`cf`）でログインしてからデプロイします。

```sh
cf auth login
pnpm deploy
```

`pnpm deploy` は `cf deploy` を実行します。Worker 名とカスタムドメイン `omni.isksss.dev` は `cloudflare.config.ts` で設定しています。カスタムドメインの利用には、Cloudflare アカウントで `isksss.dev` ゾーンを利用できる必要があります。
