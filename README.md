# OMNI — Vertical Mobility

立体機動装置で渋谷スクランブル交差点を駆け抜ける、一人称視点のフリーフライトゲームです。交差点の横断歩道や看板、街路設備を備えた街を探索し、ビルの入口から店内にも入れます。敵はプレイヤーを索敵し、建物に遮られていないときに追跡・射撃します。Three.js と Vite で構築し、Cloudflare Workers に配信します。

## 遊び方

スタート画面で **FLIGHT START** を選ぶとゲームが始まります。`Esc` で一時停止し、再開画面の **RESUME FLIGHT** から戻れます。キーボードとマウスを使う PC 向けです。

| 操作                     | 入力                                   |
| ------------------------ | -------------------------------------- |
| 移動                     | `W` `A` `S` `D`                        |
| 視点操作                 | マウス                                 |
| ジャンプ                 | `Space`（フック接続中は巻き取り）      |
| 左右のフックを射出／解除 | `Q` / `E`（照準先の建物の壁）          |
| ブースト                 | `Shift`                                |
| 武器切り替え             | `V`                                    |
| 射撃                     | 左クリック（アサルトは押し続けて連射） |
| 照準                     | 右クリックを押している間               |
| 一時停止                 | `Esc`                                  |

フック接続中の巻き取りは `Space` だけで操作します。武器はスナイパー（長射程・一撃）とアサルトマシンガン（短射程・連射）を切り替えられます。画面左上にプレイヤーの体力、敵の頭上に敵の体力が表示されます。敵の射撃で体力が尽きると交差点から再出撃します。キー割り当てはスタート画面または一時停止画面の「キー割り当て」から変更でき、ブラウザーに保存されます。上下視点の感度も同じ画面のスライダーで調整できます。敵を倒すと、しばらくして補充されます。

## ソース構成

- `src/main.js`: ゲームループ、入力、武器、HUD
- `src/city.js`: 街並み生成、建物内部・出入口、建物との衝突
- `src/enemies.js`: 敵の巡回、索敵、遮蔽物判定、攻撃
- `src/enemy-visuals.js`: 敵モデル、体力ゲージ、射撃エフェクト
- `src/flight.js`: フックの飛行物理

## 開発

Node.js と pnpm を用意して、依存関係をインストールします。

```sh
pnpm install
pnpm dev
```

開発サーバーが表示する URL をブラウザで開いてください。テスト、lint、フォーマット、ビルドは次のコマンドで実行できます。

```sh
pnpm test
pnpm lint
pnpm fmt
pnpm build
```

## Cloudflare Workers へのデプロイ

Cloudflare CLI（`cf`）でログインしてからデプロイします。

```sh
cf auth login
pnpm deploy
```

`pnpm deploy` は `cf deploy` を実行します。Worker 名とカスタムドメイン `omni.isksss.dev` は `cloudflare.config.ts` で設定しています。カスタムドメインの利用には、Cloudflare アカウントで `isksss.dev` ゾーンを利用できる必要があります。
